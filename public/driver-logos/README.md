# Driver personal marks

These files are driver brand marks, not the Formula 1 race-number artwork in
`public/driver-marks`.

- Veteran driver marks were collected from the Formula 1 driver-logo reference
  at https://1000logos.net/formula-1-drivers-logos/.
- Current 2025 rookie and younger-driver marks were collected from the
  20-driver reference at
  https://tiermaker.com/create/2025-driver-logos-17789587, then isolated from
  the labeled reference tiles.
- Franco Colapinto's FC43 vector is the header mark published at
  https://www.francolapinto.com/inicio.
- Arvid Lindblad does not currently have a verified standalone personal mark in
  this set, so the UI deliberately falls back to his official number artwork.

Sources were checked on 2026-07-18.
