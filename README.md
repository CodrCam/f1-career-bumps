# F1 Performance Dashboard

Personal F1 analytics platform with AI predictions and real-time telemetry.

## Quick Setup

```bash
npm install
npm run dev
```

## Key Features
- AI pit stop predictions
- Real-time OpenF1 API integration  
- Precision timing analysis
- Mobile-first responsive design

## Tech Stack
- React 18 + Vite
- Chart.js + OpenF1 API
- Netlify deployment

## Data Sources
- `f1_2025_season.json` - 9 rounds complete
- `Driver_Pitstop.json` - Pit stop analytics
- OpenF1 API - Live telemetry

## Deployment
Auto-deploys to Netlify on every push to main branch.
